# EmDash 后台中文补丁

适用版本：EmDash 1.3.1 / `@emdash-cms/admin` 对应3512条简体中文消息。后台继续只启用简体中文。

2026-10-26 完成通用底座补译，范围包括日历、媒体库、内容与署名字段、分类/标签、菜单、小部件、用户权限、插件、站点设置、安全、API令牌、邮件、备份、导入导出及常见错误提示。补充词典现有1928条翻译与术语修订；品牌名、编程语言名、文件名、网址示例和模板标记保留原样。

除语言包以外，补丁还处理静态按钮与提示、默认分类标签的显示，以及底层组件的开关提示。分类配置、字段标识、编辑表单的原始值、文章内容和其他业务数据不会被改写；中俄哈稿件仍按其原始语言显示。

实现：

- `src/cms/zh-CN-extra-words.json`：补充中文词典。
- `src/cms/chinese-ui.mjs`：构建时应用补丁，保留人工指定译法。不直接修改安装依赖。
- `src/cms/localize-admin.mjs`：只翻译可见文本；保留ICU变量名称、选择器、复数分支、格式参数和独立数字占位符；只在显示位置转换默认配置标签。
- `scripts/verify-admin-chinese.mjs`：扫描全部3512条消息，对比变量/复数/标签结构，检查普通英文遗漏，验证字段值与业务内容不受影响。该检查已接入 `npm run check`。

回归命令：`npm run check:admin-chinese`。升级 EmDash 时，如语言包规模或结构发生变化，检查会失败；需重新审阅补丁，不能直接放宽检查。

本次验收逐屏查看了28个后台页面，并只读检查16个官网页面、3个新闻入口与6个历史资源。未创建或修改生产文章、账号、权限、令牌和站点设置。已有其他会话的稿件运营工作保持独立。

发布后，已打开的后台页面需刷新一次以加载新的界面资源；如有未保存内容，请先保存。
