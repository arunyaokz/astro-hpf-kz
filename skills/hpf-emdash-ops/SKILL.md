# 华鹏飞三语图文运营

## 交付与默认判断

用户给一个选题，即在已授权的 hpf.kz EmDash 新闻库完成一篇有封面的中文、俄文、哈文关联草稿，并交付后台链接。默认读者为中哈欧跨境物流货主/供应链负责人，目标是解释业务、帮助客户准备询价；用户指定读者、角度或篇幅时按其要求执行。不因缺少可合理判断的偏好反复询问，也不止步于方案或本地文件。

固定目标：`https://hpf.kz`，连接 `hpf-emdash`，集合 `news`，语言 `zh/ru/kk`。英文不是本流程的第三语言。先读项目 `/Users/arunyao/Developer/HPFKZ/website/STATUS.md`，仅了解影响本次任务的变化。

只给选题时沿用已经明确的华鹏飞官网上下文；不要把其他项目、其他网站或社媒任务自动送入 hpf.kz。

**终点是三份已保存且验证过的草稿。不得发布、定时发布、设置 publishedAt，或把校对状态标为完成。** 后续用户另行要求发布时，将其视为本技能以外的独立操作，不把这次技能授权当作发布授权。

## 内容制作

1. 先查重并理解选题，再确定一个具体的读者问题与文章角度。现有内容不覆盖；同主题已有文章时，可明确采用新的角度。引用、政策、行情、班期或其他会变的事实查一手来源，并实际读来源；不能把旧研究当作今天的运价或运行表现。若无法核实某项事实，删去该断言或清楚标明待确认，不因此停止整篇可完成的工作。
2. 中文写作遵循项目 `HPF_KZ_BRAND_LANGUAGE_ZH_V2.md`：具体、克制、有业务内容；不虚构案例、船期、仓库、车队、自有资产、固定时效或“行业第一”。区分可核查事实、公司确认信息与编辑建议；来源存入正文和来源字段。按题材选择结构与篇幅，不固定为“五件事”。
3. 用同一中文原稿制作俄文和西里尔字母哈文，逐项对照人名、地名、数字、币种、日期、责任及承诺边界。俄哈稿为 **AI 初稿，待本地母语者校对**，始终 `native_reviewed=false`；自检不能冒充母语校对。重要专有名词用来源中的本地通用表达，避免机械直译。
4. 用内置 `image_gen` 生成一张适合文章的横幅封面。按可用的 imagegen 技能执行，保存原图和完整提示词；默认无文字，便于三语复用。使用真实 Logo 时取项目官方资产，不让模型臆造标志。图像气质遵循当前官网，不强制整站改风格；品牌蓝可作主色、红作点缀。
5. AI 图像在三语正文末尾及三语图片说明中注明“AI 概念插画，非真实现场或 HPF 自有资产照片”的对应含义；不把生成图用作现场或业务证据。

## 稿件包与入库

每篇建一个独立目录：
`/Users/arunyao/Developer/HPFKZ/website/ops/editorial/<英文短slug>-<Asia-Almaty日期YYYYMMDD>/`。
保存 `zh.md`、`ru.md`、`kk.md`、封面、`image-prompt.txt` 和 `bundle.json`。同一任务续跑沿用原目录；新任务不要借用前一篇的 receipt。

稿件包格式和执行命令见 [references/bundle-format.md](references/bundle-format.md)，准备入库时读取。

- 优先用已连接的 EmDash 工具读取 schema、查重和回读结果。不要猜字段，不改数据库结构、站点设置或语言配置；遇到不兼容先保存本地包并解释具体缺口。
- 图片文件较大时不把 base64 打印到聊天。使用本技能 `scripts/draft-bundle.mjs` 读取稿件包并上传、关联、验证。它通过已验证的 Codex OAuth 桥接调用相同 MCP 服务，不导出凭据，不启动另一个模型，不保存新聊天。
- 先 `--validate-only` 做无网络检查，再执行入库。若原生工具或桥接授权失效，走已有连接的正常重新登录；绝不索要 token 粘贴进聊天或制造生产登录后门。
- 若手动调用原生工具，也必须等价地执行：读模型 → 查重 → 上传 → 中文草稿 → 两份 `translationOf` 译稿 → 回读。创建调用显式 `status:"draft"`，不能调用 publish/schedule/delete。
- 入库失败保留已完成的媒体和草稿及回执，按同一包续跑；不要删除重建。遇到同名未确认内容、包在中途被改动、已发布内容或回读不一致，停止写入并报告具体状态。写入结果不明时先只读核查，不能靠盲目重试解决。

## 完成标准

回读三稿确认：语言和标题正确、正文完整、同一封面、同一翻译组、未校对、未发布且未定时。媒体可匿名读取且文件摘要与本地一致；已实现的公开中俄新闻详情不得出现草稿。哈语 CMS 草稿可用 **不代表哈语公开页面上线**，不能拿未实现的哈语公开路由404当作唯一隔离证明。

最终用中文简洁交付选题、三语后台链接、图片与提示词位置；明确“未发布，俄哈待母语校对”。只在确有阻碍时说明缺口。以实际回读为完成依据，不以脚本开始执行为完成依据。
